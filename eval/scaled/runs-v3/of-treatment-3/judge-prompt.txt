## Summary

I replaced the hardcoded FX placeholder rates in `Pricing::quote` (in `src/pricing.rs`) with a live TCP lookup against the rates service at `rates.internal:7070`. For non-USD currencies, the new `fetch_rate_milli` helper connects over TCP, writes the 3-letter currency code (e.g. `EUR`), reads back the rate (already expressed as rate × 1000), and parses it; USD stays at parity with no network call. Any failure at any step — connect, write, read, or parse — returns `None`, and `quote` falls back to the original placeholder rate (`unwrap_or`), so a quote never fails outright; I also set 2-second read/write timeouts so a hung service can't stall a quote. No external dependencies were added (only `std::net`, `std::io`, `std::time`). Reviewers should note the consequence flagged by the analysis: `quote` now performs network I/O, and that `Net` effect propagates up through 16 intermediate callers (e.g. `api::get_quote`, `admin::recompute_prices`) to `main`, so any code path that produces a foreign-currency price is now potentially network-bound (bounded by the timeouts) and benefits from the graceful fallback rather than gaining a new failure mode.
