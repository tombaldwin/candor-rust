## Summary
I replaced the hardcoded FX placeholder in `src/pricing.rs`'s `Pricing::quote` with a live lookup against the rates service at `rates.internal:7070`. For any non-USD currency the new `fetch_rate_milli` helper opens a TCP connection (with 2-second connect/read/write timeouts), writes the 3-letter currency code (`EUR`/`GBP`, via a new `currency_code` mapping), reads back the response, and parses it as the rate × 1000; USD stays at parity and never hits the network. Only the standard library is used (`std::net`, `std::io`, `std::time`), so no dependencies were added. Reviewers should note one behavioral consequence: `quote` (and therefore `quote_bulk`, which calls it per SKU) now performs blocking network I/O for non-USD currencies — `quote_bulk` makes one connection per SKU, so bulk foreign-currency quotes may be noticeably slower or stall up to the timeout if the rates service is unreachable.
