## Summary
I replaced the hardcoded FX rates in `Pricing::quote` (in `src/pricing.rs`) with a live TCP lookup. For non-USD currencies, `quote` now calls a new `fetch_rate_milli` helper that connects to `rates.internal:7070`, writes the 3-letter currency code (via a new `currency_code` mapping over the `Currency` enum), reads back the rate-times-1000 as a text integer, and parses it. The previously hardcoded values are retained as named `placeholder` fallbacks: any connection, read, or parse failure causes `fetch_rate_milli` to return `None` and the quote falls back to the placeholder, so a quote never fails outright. USD short-circuits to parity with no network call, and I used bounded connect/read/write timeouts (2s) so an unreachable or slow rates service can't hang a quote. Only the standard library is used (`std::net`, `std::io`, `std::time`), so no new dependencies were added; reviewers should note that `quote`/`quote_bulk` now perform blocking network I/O where they were previously pure, which has latency and testability implications for any callers that assumed they were side-effect-free.
