## Summary
I replaced the hardcoded FX rates in `Pricing::quote` (`src/pricing.rs`) with a live lookup. A new private `fetch_live_rate` helper opens a TCP connection to `rates.internal:7070`, writes the 3-letter currency code (e.g. `EUR`), reads back the response, and parses it as an integer rate × 1000 — exactly the `rate_milli` format `Money::convert` already expects. In `quote`, USD still uses parity (no lookup needed since it's the base currency), while EUR/GBP attempt the live fetch and fall back to the original placeholder rate via `unwrap_or` on any connect/read/parse failure, so a quote never fails outright. Only the standard library is used (`std::net::TcpStream`, `std::io`, `std::time::Duration`), and short read/write timeouts were added so an unresponsive service degrades to the fallback rather than hanging. Reviewer note: `quote` (and therefore `quote_bulk`) now performs blocking network I/O per non-USD SKU, so callers in hot paths or loops may see added latency when the rates service is slow — and `quote_bulk` will make one TCP round-trip per SKU.
