## Summary
I replaced the hardcoded FX placeholders in `Pricing::quote` (in `src/pricing.rs`) with a live lookup against the rates service at `rates.internal:7070`. For non-USD currencies, a new `fetch_live_rate_milli` helper opens a TCP connection (with 2-second connect/read/write timeouts), writes the 3-letter currency code (via a new `currency_code` mapping), reads the response, and parses it as the rate × 1000; USD short-circuits to parity with no network call. Any connection, read, or parse failure returns `None`, and `quote` falls back to the original placeholder rates (now in `placeholder_rate_milli`), so a quote never fails outright. No new dependencies were added — only `std::net`, `std::io`, and `std::time`. Reviewers should note the new network effect: candor reports that `fetch_live_rate_milli` introduces a `Net` effect that propagates up through `quote`/`quote_bulk` into 16 intermediate callers (e.g. `api::get_quote`, `api::list_quotes`, `api::post_checkout`, `admin::recompute_prices`) and surfaces at `main`, meaning any quote-producing path can now perform blocking I/O.
