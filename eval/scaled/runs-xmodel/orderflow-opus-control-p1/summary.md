## Summary
I replaced the hardcoded FX rates in `Pricing::quote` (src/pricing.rs) with a live lookup against the rates service at `rates.internal:7070`. For any non-USD currency, `quote` now calls a new private helper `fetch_rate_milli`, which opens a TCP connection, writes the 3-letter currency code (e.g. `EUR`), reads back the rate (as rate × 1000, matching the existing `rate_milli` convention consumed by `Money::convert`), and parses it as an `i64`. Every failure path — connect, write, read, or parse — returns `None` via `Option`/`?`, and the caller uses `unwrap_or(placeholder_milli)` so a quote silently falls back to the original placeholder rate and never fails. USD short-circuits to parity with no network call. The change adds a network I/O side effect to `Pricing::quote` (and transitively `quote_bulk`), which was previously pure; reviewers should note that non-USD quotes now perform blocking TCP I/O with a 2-second connect/read/write timeout, so any code path or test exercising foreign-currency quotes may incur that latency when the service is unreachable. Only the standard library is used and the build passes with no new dependencies.
