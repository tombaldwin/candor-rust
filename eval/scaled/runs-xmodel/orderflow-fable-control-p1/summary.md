## Summary
I replaced the hardcoded EUR/GBP FX placeholders in `Pricing::quote` with a live lookup against `rates.internal:7070`. A new private helper `fetch_rate_milli(code)` opens a `TcpStream` (2-second timeouts), writes the code, reads the reply, parses it as rate × 1000 — the exact unit `Money::convert` expects, so no changes in `money.rs`. USD stays at parity; EUR and GBP fall back via `.unwrap_or(920)`/`.unwrap_or(790)` on any failure, so a quote never fails outright. The only behavioral consequence for reviewers: `quote` (and therefore `quote_bulk` and everything downstream that prices in a foreign currency) now performs blocking network I/O on each non-USD call, where it was previously pure — worth noting for latency-sensitive or hot paths. std only.
