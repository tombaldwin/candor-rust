## Summary
I replaced the hardcoded FX rate lookup in `Pricing::quote` with a live lookup against `rates.internal:7070`: for non-USD currencies it opens a `TcpStream` (500ms timeouts), writes the 3-letter currency code, reads the response, parses it as rate × 1000. USD short-circuits to parity. Any failure falls through via `.ok()?` to `fetch_live_rate_milli` returning `None`, triggering `unwrap_or_else` fallback to placeholder rates. Only std used. One consequence: `quote` (and therefore `quote_bulk`) now performs blocking network I/O for non-USD currencies on every call with no caching, so callers issuing many quotes in a loop incur repeated round-trips.
