## Summary
I replaced the hardcoded EUR/GBP rates in `Pricing::quote` (src/pricing.rs) with a live lookup: a new private `fetch_rate_milli` helper connects to `rates.internal:7070` over TCP, writes the code, reads the response, parses it as rate × 1000. Any failure yields `None` and `quote` falls back to placeholder rates; USD stays at parity. 2-second timeouts. Reviewers should note that `quote` (and everything downstream: `quote_bulk`, checkout, reports, the API handlers — 16 callers per the candor diff) is no longer pure: it now performs network I/O per non-USD quote, with no caching. The candor effect diff confirms `+Net` propagating from `fetch_rate_milli` to `main` (via `admin::recompute_prices`, `api::get_quote`, `api::list_quotes`, `api::post_checkout`, and more), plus an `+Unknown` because the engine can't fully resolve the std networking internals.
