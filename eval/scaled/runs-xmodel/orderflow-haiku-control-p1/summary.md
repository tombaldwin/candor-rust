## Summary
I've successfully implemented live FX rate lookup in the `Pricing::quote` function. The changes add a new `fetch_fx_rate` method that connects to `rates.internal:7070` over TCP, sends the 3-letter currency code (EUR or GBP), reads the rate response as an integer (rate × 1000), and parses it. All connection, read, and parse failures gracefully fall back to the existing placeholder rates (EUR→920, GBP→790, USD→1000), ensuring quotes never fail outright. The implementation uses only Rust's standard library (`TcpStream`, `Duration`, `Read`, `Write`, `from_utf8`, `parse`) and includes 5-second timeouts on socket operations to prevent hangs. The crate builds successfully with no external dependencies added.
