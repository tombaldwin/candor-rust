## Summary
I replaced the hardcoded FX rates in `Pricing::quote` with a live TCP lookup against `rates.internal:7070`. A new helper `fetch_rate_milli` connects, writes the currency code, reads rate×1000, parses it. Every failure returns `None` so `quote` falls back; 2-second timeouts. USD short-circuits. std only.
Reviewer note from `cargo-candor diff`: `fetch_rate_milli` newly introduces `Net` (TCP I/O) and an `Unknown` effect, and because `quote`/`quote_bulk` are on the hot path, those effects propagate through 16 intermediate callers (e.g. `api::get_quote`, `api::post_checkout`, `admin::recompute_prices`) all the way up to `main`. The `Unknown` flag means candor can no longer prove that function's effect set is complete — expected for std net I/O. Downstream callers that assumed pricing was side-effect-free (caching, test determinism) should be aware they now perform network I/O.
