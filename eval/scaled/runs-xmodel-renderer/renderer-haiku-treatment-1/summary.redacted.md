## Summary

The `Engine::expand` function was enhanced to support `{{exec:CMD}}` template directives, which execute shell commands via `std::process::Command` and expand to their trimmed stdout output. A new private method `Engine::exec_command` was added to handle the command execution logic. This new `Exec` effect transitively reaches all public entry points in the codebase: `main`, `api::render_one`, `api::render_many`, `page::Page::render`, and `page::Page::render_token` all now perform process execution when templates contain exec directives. Reviewers should be aware that any template content passed through the rendering pipeline can now trigger arbitrary shell commands, creating both capability and security surface that must be carefully controlled at the caller level.
