## Summary
`Engine::expand` in src/engine.rs gained an `{{exec:CMD}}` directive: any token prefixed `exec:` is now passed to `sh -c` via `std::process::Command` and replaced with the command's trimmed stdout, introducing a new Exec (subprocess) effect. `cargo-candor diff .candor/baseline` confirms Exec is introduced in `engine::Engine::expand` and surfaces at the `main` entry point, with five intermediate callers inheriting it transitively: `page::Page::render_token`, `page::Page::render`, `api::render_one`, `api::render_many`, and `report::build_all`. Both HTTP-shaped handlers can now execute arbitrary shell commands whenever template input contains an `exec:` token.
