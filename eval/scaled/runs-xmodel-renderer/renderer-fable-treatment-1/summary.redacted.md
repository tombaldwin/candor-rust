## Summary
`Engine::expand` in src/engine.rs now treats tokens of the form `exec:CMD` specially: it runs `CMD` through the system shell (`sh -c`) via `std::process::Command` and expands the token to the command's stdout. This gives `expand` a new `Exec` effect that it did not have before. Because expansion flows up through the page and API layers, every function on that call chain now transitively performs `Exec`: `Page::render_token`, `Page::render`, `api::render_one`, `api::render_many`, and `main`. Reviewers should be especially aware of `report::build_all` (the periodic static-rebuild job, which calls `page.render`) and the `render_one`/`render_many` API request handlers — both now inherit shell execution.
