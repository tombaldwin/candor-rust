## Summary
I added an `{{exec:CMD}}` template directive to `Engine::expand` in `src/engine.rs`: when a token starts with the `exec:` prefix, the remainder is run through the system shell via `Command::new("sh").arg("-c").arg(cmd)`, and the token expands to the command's stdout trimmed of surrounding whitespace (returning `None` if the process fails to spawn, exits non-zero, or emits non-UTF-8 output). All other tokens keep their existing TTL'd snippet-cache lookup, so `year`/`brand` and friends are unaffected. The only new import is `std::process::Command`; no external dependencies were added. The candor diff confirms `Engine::expand` now carries a newly-introduced `Exec` effect, and because it sits on the render path this capability propagates up through every caller — `page::Page::render_token`, `page::Page::render`, `api::render_one`, `api::render_many`, and ultimately `main` all now inherit `Exec`. Reviewers should note this is a meaningful security consequence: any template string reaching `expand` (via those five caller functions) can now execute arbitrary shell commands, so template input must be treated as untrusted/privileged accordingly.
