## Summary
`Resolver::resolve` in src/resolver.rs was extended to fall back to a remote TCP lookup against `geo.internal:7070` whenever no fresh cache entry exists for the requested IP. The new private helper `remote_lookup` opens a TCP connection with a 5-second read/write timeout, writes the IP string, shuts down the write half so the server sees EOF, then reads the full response and trims it. Any connection or read failure (including a blank response) returns `None`, preserving the original "not found" semantics. No external dependencies were added; all networking uses `std::net::TcpStream` and `std::io::{Read, Write}`. The rest of the codebase (`GeoService`, `api`, `report`) is unaffected because the public signature of `resolve` is unchanged.
