## Summary
Modified `Cache::get` in src/cache.rs to implement a disk fallback on cache miss. When a key is absent from the in-memory map or its TTL has expired, the method now attempts to read the file at `/var/cache/<key>` using `std::fs::read_to_string`; any I/O error (file not found, permission denied, etc.) is silently treated as "not found" and `None` is returned. Two new standard-library imports were added (`std::fs` and `std::path::PathBuf`); no external dependencies were introduced. The change is backward-compatible: callers such as `Service::lookup` and `Service::batch` continue to receive an `Option<String>` with the same semantics, but will now transparently pick up values from disk when the in-memory cache cannot satisfy the request. Reviewers should be aware that the file contents are returned as-is (including any trailing newline), which may differ from values stored via `Cache::put`.
