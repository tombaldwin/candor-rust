## Summary
Added a `remote_lookup` free function in src/resolver.rs that opens a TCP connection to `geo.internal:7070`, writes the queried IP (newline-terminated), reads back the response with `read_to_string`, trims it, and returns `None` on any I/O failure or empty response. `Resolver::resolve` now falls through to `remote_lookup` whenever the in-memory cache has no entry for the IP or its entry has exceeded the TTL, keeping the happy-path cache-hit behaviour unchanged. The candor effect diff shows that `resolver::remote_lookup` introduces the `Net` effect for the first time in this crate; that effect propagates up through `resolver::Resolver::resolve`, both service methods (`locate` and `batch`), and all three callers in `api` and `report`, reaching `main` — so every public entry point now carries an undeclared `Net` effect that reviewers should be aware of. No external dependencies were added.
