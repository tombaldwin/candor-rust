## Summary
The only file changed is src/cache.rs. The `Cache::get` method was refactored from a short-circuit `?`-based chain into an explicit two-stage lookup: it first checks the in-memory `HashMap` and returns immediately if the entry is present and within its TTL, then falls back to reading `/var/cache/<key>` using `std::fs::read_to_string`, returning `None` for any I/O error (missing file, permission denied, etc.). Two new standard-library imports were added — `std::fs` and `std::path::PathBuf` — which are the only new dependencies. The public interface of `Cache::get` is unchanged, so no callers (`service.rs`, `api.rs`, `report.rs`) required any modification. Reviewers should be aware that the disk fallback returns the raw file contents including any trailing newline, which may differ from values inserted via `put`; if callers are sensitive to trailing whitespace, a `.trim_end()` step may be warranted.
