## Summary
`Engine::expand` in src/engine.rs was modified to handle tokens prefixed with `exec:`. When such a token is encountered, the suffix is passed to `sh -c` via `std::process::Command`, and the trimmed stdout is returned as the expansion; a non-zero exit status or spawn failure returns `None`, matching the existing behaviour for unknown tokens. All other tokens continue through the TTL'd snippet cache unchanged. No new external dependencies were introduced. The candor effect analysis shows that `Engine::expand` gained the `Exec` effect, which propagates up through the full call chain: `page::Page::render_token` → `page::Page::render` → `api::render_one` / `api::render_many` / `report::build_all` → `main`. Reviewers should be aware that any caller of `Engine::expand` (or any function that uses the `Page` rendering layer) can now transitively spawn arbitrary shell commands — this is a significant capability escalation and should be gated behind appropriate input validation or trust boundaries in production use.
