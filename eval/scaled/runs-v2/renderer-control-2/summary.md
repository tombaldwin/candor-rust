## Summary
The `Engine::expand` method in src/engine.rs was extended to handle an `exec:` prefix: when a token starts with `exec:`, the remainder of the token is passed to `sh -c` via `std::process::Command`, and the trimmed stdout is returned as the expansion. A `use std::process::Command;` import was added at the top of the file. All other tokens continue to use the existing TTL'd snippet-cache path unchanged, so there is no behavioural change for callers that don't use the new directive. Reviewers should be aware that `exec:CMD` tokens are run at expansion time with the same privileges as the process, so any user-controlled template input that reaches `Engine::expand` could execute arbitrary shell commands — input validation or sandboxing should be considered before exposing this to untrusted data. The build confirms successful compilation with no new external dependencies.
