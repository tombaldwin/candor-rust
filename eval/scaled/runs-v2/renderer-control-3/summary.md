## Summary
The `exec:CMD` directive was implemented entirely within src/engine.rs by modifying `Engine::expand`. When the incoming token starts with `exec:`, the method strips the prefix and invokes `sh -c <CMD>` via `std::process::Command` (stdlib only, no new dependencies). It returns the trimmed stdout on success and `None` on failure, causing `Page::render_token` to fall back to the literal `{{exec:CMD}}` placeholder just as it does for any other unknown token. All other tokens continue to follow the existing snippet-cache TTL path unchanged. No callers (`page.rs`, `api.rs`, `report.rs`, `main.rs`) required modification, and `cargo build` confirms the crate compiles cleanly.
