## Summary
Added `exec:CMD` template directive support to `Engine::expand` in src/engine.rs. When a token begins with the `exec:` prefix, the method uses `std::process::Command` to invoke `sh -c <CMD>`, captures stdout, trims whitespace, and returns the result; tokens without the prefix continue through the existing snippet-cache path unchanged. No new dependencies were added — only `std::process::Command` from the standard library is used. The candor effect diff shows that `engine::Engine::expand` now carries the new `Exec*` effect (introduced here), which propagates upward through `page::Page::render_token`, `page::Page::render`, `api::render_one`, `api::render_many`, `report::build_all`, and ultimately surfaces at the `main` entry point. Reviewers should be aware that any caller of `Engine::expand` (and transitively `Page::render`) can now trigger arbitrary subprocess execution when a token matching `exec:…` is passed in — this is intentional for the feature but represents a significant new capability that callers should validate or restrict at their trust boundary.
