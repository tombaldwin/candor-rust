## Summary
`Cache::get` in src/cache.rs was updated to fall back to reading `/var/cache/<key>` from disk when the in-memory map has no valid entry for a key (either the key is absent or its TTL has expired). The implementation uses `std::fs::read_to_string` on a `Path` constructed by joining `/var/cache` with the key string; a missing or unreadable file returns `None` via `.ok()`, preserving the existing "not found" semantics. Two additional standard-library imports (`std::fs` and `std::path::Path`) were added — no external dependencies were introduced. Reviewers should be aware that the key string is used verbatim as a filename component, so callers supplying keys containing path separators or other special characters could cause unexpected filesystem traversal; input sanitisation may be worth adding if keys are user-controlled. The rest of the codebase (`service.rs`, `api.rs`, `report.rs`) is unaffected because they interact with the cache solely through the unchanged public `get` and `put` signatures.
