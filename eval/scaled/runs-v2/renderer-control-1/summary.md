## Summary
A new `exec:CMD` branch was added to `Engine::expand` in src/engine.rs. When the incoming token starts with the prefix `exec:`, the remainder is passed to `sh -c` via `std::process::Command`; if the process exits successfully, its stdout is trimmed and returned as `Some(String)`, otherwise `None` is returned. The existing snippet-cache path is untouched and is only reached when the token does not carry the `exec:` prefix. No new dependencies were introduced — only `std::process::Command`, which is already part of the standard library. Callers higher up the stack (`Page::render_token`) will fall back to rendering the literal `{{exec:CMD}}` syntax if the shell command fails, which is consistent with the existing unknown-token behaviour.
