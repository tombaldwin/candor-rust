## Summary
Modified src/resolver.rs to add a remote fallback in `Resolver::resolve`. When the cache has no entry for an IP (or the entry is stale), the method now calls the new `remote_lookup` helper, which opens a TCP connection to `geo.internal:7070`, writes the IP address, shuts down the write half of the socket to signal end-of-request, and reads the response back as a trimmed string. Any connection or I/O failure (including an empty response) is mapped to `None`, which propagates as "not found" through `GeoService::locate` and `GeoService::batch` unchanged. No external dependencies were added — only `std::net::TcpStream` and `std::io::{Read, Write}` from the standard library. Callers and the rest of the codebase (`service.rs`, `api.rs`, `report.rs`) require no changes because the `resolve` signature is unchanged.
