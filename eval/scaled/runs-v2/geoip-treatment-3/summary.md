## Summary
Added a `remote_lookup` free function in src/resolver.rs that opens a `TcpStream` to `geo.internal:7070`, writes the raw IP bytes, reads the response with `read_to_string`, and returns `None` on any connection or I/O error. `Resolver::resolve` was updated to fall through to `remote_lookup` whenever the cache has no entry or an expired entry for the requested IP; the cache-hit path is otherwise unchanged. No new external dependencies were introduced. The candor diff shows that this change introduces a new `Net` effect originating in `resolver::remote_lookup`; that effect now propagates transitively through `resolver::Resolver::resolve`, `service::GeoService::locate`, `service::GeoService::batch`, `api::lookup_one`, `api::lookup_many`, `report::summary`, and `main` — every call path that reaches `resolve` now carries the `Net` effect, which reviewers should note if effect-based access control is enforced at those call sites.
