## Summary
Modified `Cache::get` in src/cache.rs to fall back to reading `/var/cache/<key>` using `std::fs::read_to_string` when the in-memory cache has no valid entry for the key. A missing or unreadable file is silently treated as "not found" via `.ok()`. No new external dependencies were added; only `std::fs` and `std::path::Path` from the standard library were imported. The candor effect checker reports that `Cache::get` gained the `Fs` (filesystem read) effect, which propagates up through all callers: `service::Service::lookup`, `service::Service::batch`, `api::get_one`, `api::get_many`, `report::build`, and ultimately `main`. Reviewers should be aware that every call path that previously had no I/O now performs a potential disk read on cache miss, which has implications for latency, error handling, and sandboxing in production environments.
