## Summary
Added a `remote_lookup` associated function to `Resolver` in src/resolver.rs that opens a TCP connection to `geo.internal:7070`, writes the IP address, reads back the location string, and returns `None` on any connection or I/O failure. The existing `resolve` method was updated to fall through to this remote call when no fresh cached entry exists. No external dependencies were added — only `std::net::TcpStream` and `std::io::{Read, Write}` from the standard library are used. The candor effect diff shows a new `Net` effect introduced in `Resolver::remote_lookup` that propagates up through `Resolver::resolve`, `GeoService::locate`, `GeoService::batch`, `api::lookup_one`, `api::lookup_many`, `report::summary`, and `main` — reviewers should be aware that every call path into the resolver can now perform outbound network I/O, which may require adjustment to capability policies or sandboxing configuration.
