## Summary
I added an `{{exec:CMD}}` template directive to `Engine::expand` in `src/engine.rs`. When the token starts with the `exec:` prefix, the remainder is run via the system shell (`std::process::Command::new("sh").arg("-c").arg(cmd)`) and the token expands to the command's stdout, trimmed; all other tokens retain their existing TTL'd snippet-cache behaviour. This required only a new `use std::process::Command;` import and a short early-return branch, with no new external dependencies (standard library only). The consequence reviewers should note is that `expand` is no longer a cheap snippet lookup: the candor diff confirms it gains an `Exec` effect that propagates transitively through all 5 intermediate callers (`page::Page::render_token`, `page::Page::render`, `api::render_one`, `api::render_many`, `report::build_all`) up to `main` — 7 functions across 4 files. Most notably, `report::build_all` runs in a periodic rebuild job documented to assume rendering is cheap, so it can now spawn subprocesses; additionally, passing untrusted token text into `sh -c` is a command-injection surface that should be gated or sanitized before exposing this to external input.
